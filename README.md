# Courier Drive

Unity와 C#을 활용해 제작한 2D 배달 주행 게임 프로젝트입니다.

맵을 주행하면서 배달 물품을 획득하고, 지정된 목적지에 배달하는 간단한 게임입니다.
Unity 2D의 기본 기능과 C# 게임 프로그래밍을 학습하기 위해 제작했습니다.

## 프로젝트 소개

* **게임 장르:** 2D 캐주얼 / 드라이빙
* **게임 엔진:** Unity
* **사용 언어:** C#
* **개발 목적:** Unity 2D 및 C# 게임 개발 학습

## 주요 기능

* 차량 이동 및 조작
* 충돌 및 Trigger 처리
* 배달 물품 획득
* 배달 목적지 판정
* 차량 속도 변화
* Unity 2D Physics를 활용한 상호작용

## 학습 내용

이 프로젝트를 통해 다음 내용을 학습했습니다.

* Unity의 기본 GameObject 및 Component 구조
* `MonoBehaviour` 생명주기
* `Update()`를 활용한 플레이어 입력 처리
* `Collider2D`를 활용한 충돌 처리
* `OnCollisionEnter2D()`
* `OnTriggerEnter2D()`
* `SerializeField`를 활용한 Inspector 데이터 관리
* C#을 활용한 기본적인 게임 로직 구현
